## 🐾 SafePaws

**SafePaws** is an innovative web platform built to support animals in need by connecting shelters with vital resources and fostering collaboration within the animal welfare community.  
It centralizes tools for reporting lost or found pets, promoting adoptions, and sharing essential pet care info — all in one place.

This project was created as part of a course and reflects my growing skills in full-stack development (and my love for animals 🐶🐱).

### 🧩 Key Features:
- Report lost or found pets 🐕‍🦺  
- Adopt or foster pets 🏡  
- Access pet care and welfare resources 📚
